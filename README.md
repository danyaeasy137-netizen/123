# Gift Tracker — трекер листингов NFT-подарков Telegram

Отслеживает новые выставления подарков на продажу на внутреннем маркете
Telegram (за ⭐) через пользовательскую сессию и шлёт уведомления в чат/канал.

Использует официальный (документированный) MTProto-метод
`payments.getResaleStarGifts` — тот же, которым пользуется официальное
приложение Telegram для показа маркета.

## Установка

```bash
pip install -r requirements.txt
```

## Архитектура

- **Сессия (Telethon, api_id/api_hash/phone)** — используется только для
  чтения маркета через MTProto (`payments.getResaleStarGifts`). Bot API
  такого метода не имеет — это доступно только обычным клиентским сессиям.
- **Бот (bot_token)** — используется только для отправки уведомлений в чат
  через Bot API. Сообщения приходят от имени бота, а не от вашего личного
  аккаунта.

Чтобы бот мог писать в нужный чат/тему — добавьте его туда и выдайте право
отправлять сообщения (если это супергруппа с темами — право видеть темы
тоже нужно).

## Настройка

1. Получите `api_id` и `api_hash` на https://my.telegram.org → API development tools.
2. Скопируйте `config.example.json` в `config.json`.
3. Заполните `api_id`, `api_hash`, `phone` (эти три — для сессии, которая читает маркет).
4. Создайте бота через @BotFather, получите `bot_token` и впишите в конфиг
   (этот бот будет отправлять уведомления).
5. Укажите `target_chat` — куда слать уведомления (бот должен быть добавлен
   в этот чат/канал с правом писать).
5. При необходимости укажите `gift_ids` — список конкретных числовых ID
   типов подарков, если хотите отслеживать не все, а только некоторые
   (по умолчанию пусто = отслеживаются все типы, доступные к перепродаже).
6. Если нужно слать не в общий чат, а в конкретную **тему** супергруппы
   с топиками (forum), укажите `target_topic_id` — это ID сообщения-темы.
   Для ссылки вида `https://t.me/c/4423380440/3`:
   - `target_chat` = `-100` + число из ссылки → `-1004423380440`
   - `target_topic_id` = `3` (последнее число в ссылке)

## Первый запуск

```bash
python tracker.py
```

При первом запуске Telethon попросит код подтверждения от Telegram (придёт
в приложение). После успешного входа скрипт выведет в консоль строку
`session_string` — скопируйте её в `config.json`, чтобы при последующих
запусках не логиниться заново.

## Как это работает

- Раз в `refresh_gift_types_seconds` (по умолчанию 10 минут) скрипт получает
  список типов подарков, которые вообще можно перепродавать
  (`payments.getStarGifts`).
- Каждые `poll_interval` секунд (по умолчанию 4) скрипт запрашивает первую
  страницу листингов по каждому типу подарка (`payments.getResaleStarGifts`,
  сортировка по умолчанию — по времени последнего изменения цены/выставления,
  т.е. свежие вперёд).
- Сравнивает полученные ID листингов с уже виденными (хранятся в
  `state.json`) и отправляет уведомление только по новым.
- При первом обнаружении нового *типа* подарка существующие листинги
  просто запоминаются без спама — уведомления шлются только по-настоящему
  новым выставлениям, появившимся после запуска.

## О скорости опроса

Не ставьте `poll_interval` слишком маленьким (доли секунды). Если типов
подарков десятки, это десятки запросов в секунду с одной сессии —
Telegram почти гарантированно ответит `FloodWaitError` и временно
ограничит аккаунт. Скрипт уже сам ловит `FloodWaitError` и ждёт нужное
время, но лучше сразу выставить разумный интервал (3–6 секунд) и при
необходимости сузить список отслеживаемых `gift_ids` до тех подарков,
которые вам реально интересны — так апдейты по ним будут чаще при том же
общем количестве запросов.

## Отладка полей

Названия некоторых полей ответа (особенно поле с ценой перепродажи) могут
отличаться в зависимости от версии схемы Telethon. Если в уведомлениях
цена выводится как `?`, запустите:

```bash
python tracker.py --debug
```

Это напечатает сырой объект первого найденного листинга — посмотрите на
реальное название поля с ценой и поправьте список `attr` в функции
`format_price()` в `tracker.py`.

## Важно

- Используется ваша **личная сессия** (не Bot API) — это единственный
  способ получить доступ к маркету через MTProto, но это также означает,
  что скрипт действует от имени вашего аккаунта. Не публикуйте
  `session_string` — по ней можно полностью войти в аккаунт.
- Слишком агрессивный опрос может привести к временным ограничениям
  аккаунта со стороны Telegram — see раздел выше.
